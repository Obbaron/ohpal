# AMPM Viewer 2.1.1

A roomier toolbar with keyboard shortcuts, and Add from Excel that works on the
samples template without changing anything.

**Download**

- **Windows:** `ampm-viewer-v2.1.1-x64-setup.exe`. Run it to install, or to
  upgrade an earlier version in place (your settings, macros and plots are kept).
- **macOS (Apple silicon):** `ampm-viewer-v2.1.1-arm64.dmg`. Open it and drag
  AMPM Viewer to Applications, replacing the old one.

### What's new

- **A bigger toolbar, in named groups.** Larger icons, grouped as in Office's
  ribbon, with each group's name underneath (Columns, Filters, Plots, Macros...).
  Hover a button for its name and shortcut. The Deselect button is gone: click
  empty space, or press Esc in the grid.
- **Keyboard shortcuts.** Ctrl+B shows or hides the side panel; Alt+Down / Alt+Up
  step through the layers; Ctrl+Tab moves between tabs; F2 renames a column;
  Ctrl+F adds a filter; Ctrl+N opens New plot; Ctrl+E exports to Excel; on a plot,
  Ctrl+0 resets the view and Ctrl+Shift+S saves a screenshot. Also Ctrl+O open,
  Ctrl+W close and Ctrl+, settings. Use Cmd on a Mac. Help > Keyboard and mouse
  lists them all.
- **Add from Excel works on the samples template.** Columns you fill in on the
  template (a density, say) now import on `part_id`; before, the column came out
  empty. The dialog also starts on the right choices: the part column as the key,
  your next measurement column as the value, matched on `part_id`. It says how
  many keys match, and asks before adding a column nothing matches.
- **LaserVIEW (mean) is hidden in the table by default.** It is still loaded (the
  melt-pool correction needs it); show it from Show/hide columns.

### First start

Neither installer is signed yet. On Windows, if SmartScreen stops the setup,
choose **More info**, then **Run anyway**. On a Mac, the first time: macOS 15
and later, open AMPM Viewer, close the warning, then System Settings > Privacy &
Security > **Open Anyway**; macOS 14 and earlier, Control-click AMPM Viewer in
Applications and choose **Open**.

See `CHANGELOG.md` for the details.
