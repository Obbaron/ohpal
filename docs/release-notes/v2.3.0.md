# AMPM Viewer 2.3.0

Builds exported by an older version of the DataHUB open, with only the
columns they have.

**Download**

- **Windows:** `ampm-viewer-v2.3.0-x64-setup.exe`. Run it to install, or to
  upgrade an earlier version in place (your settings, macros and plots are kept).
- **macOS (Apple silicon):** `ampm-viewer-v2.3.0-arm64.dmg`. Open it and drag
  AMPM Viewer to Applications, replacing the old one.

### Added

- **Older DataHUB exports open.** Builds exported by an older DataHUB have
  seven columns under older names (`Start time / us`, `x position / mm`,
  `LaserVIEW`, `MeltVIEW Melt Pool`, ...), and opening one stopped with
  "missing expected columns". They now open like any build: the columns are
  read under their current names (`Start time`, `Demand X`, `LaserVIEW (mean)`,
  `MeltVIEW melt pool (mean)`, ...), so formulas, macros and plots work on them
  unchanged, and the melt-pool correction works as on a current build.
- Only the columns a build has are offered on the DataStore setup page and
  loaded, so an older build shows no empty focus, laser power, back
  reflection or median columns.
- The build's **Info** page has a new **Packet data** row saying which layout
  the build uses.

### Changed

- **A build mixing the two layouts is refused**, for example when some layers
  were exported again with a newer DataHUB. The message, *This build mixes
  DataHUB exports*, names a layer of each, and nothing is converted. A stacked
  build whose steps mix layouts is refused the same way (**Add step...** in
  New stacked build says so).
- "Load failed" in the status bar now shows the error's own message.

Builds in the current layout are unaffected: they load the same data as in
2.2.1, and their DataStores are reused as they are, with no rebuild.

### First start

Neither installer is signed yet. On Windows, if SmartScreen stops the setup,
choose **More info**, then **Run anyway**. On a Mac, the first time: macOS 15
and later, open AMPM Viewer, close the warning, then System Settings > Privacy &
Security > **Open Anyway**; macOS 14 and earlier, Control-click AMPM Viewer in
Applications and choose **Open**.

See `CHANGELOG.md` for the details.
