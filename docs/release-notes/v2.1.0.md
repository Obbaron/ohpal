# AMPM Viewer 2.1.0

Better help choosing DBSCAN's radii, panning in 3D plots, a Close that starts
afresh, and DBSCAN part assignment that isn't redone on every rebuild.

**Download**

- **Windows:** `ampm-viewer-v2.1.0-x64-setup.exe`. Run it to install, or to
  upgrade 2.0.1 in place (your settings, macros and plots are kept).
- **macOS (Apple silicon):** `ampm-viewer-v2.1.0-arm64.dmg`. Open it and drag
  AMPM Viewer to Applications, replacing the old one.

### What's new

- **K-distance curve finds the knee for you.** A dot and a dashed line mark the
  curve's knee, labelled with the radii it suggests: eps XY and eps Z, at the
  ratio you set. Hover anywhere on the curve to see the radii there, the share of
  points that would have enough neighbours (DBSCAN's core points), and how steep
  the curve is. The old eps line is gone.
- **Pan in 3D plots** with a right drag. Left drag still rotates, scroll zooms.
- **File > Close closes everything:** the build and every plot, as if you had
  restarted the app. Everything is saved first and comes back when you reopen
  the build.
- **DBSCAN part assignment is kept** across rebuilds and reopening, and when the
  build folder moves. It only runs again when the layers, the parts CSV, the STL
  or the DBSCAN settings change.
- **Excel template:** you now choose where to save it.
- **Log:** DBSCAN's progress is written to the log; loading a layer no longer is.
- No more "could not determine DPI" warning for every plot on Linux.

### First start

Neither installer is signed yet. On Windows, if SmartScreen stops the setup,
choose **More info**, then **Run anyway**. On a Mac, the first time: macOS 15
and later, open AMPM Viewer, close the warning, then System Settings > Privacy &
Security > **Open Anyway**; macOS 14 and earlier, Control-click AMPM Viewer in
Applications and choose **Open**.

See `CHANGELOG.md` for the details.
