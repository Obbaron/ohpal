# AMPM Viewer 2.0.1

AMPM Viewer now comes with installers for Windows and macOS, and starts in a
fraction of the time.

**Download**

- **Windows:** `ampm-viewer-v2.0.1-x64-setup.exe`. It installs for you alone, with
  no administrator rights needed, and later versions upgrade it in place.
- **macOS (Apple silicon):** `ampm-viewer-v2.0.1-arm64.dmg`. Open it and drag
  AMPM Viewer to Applications.

### What's new

- **Much faster start.** The app no longer unpacks itself (about 550 MB) to a
  temporary folder every time it starts.
- **Double-click a `.ampmplot`** plot-library file to open it, in the AMPM Viewer
  that's already running or in a new one.
- **Uninstalling tidies up.** It lists what else AMPM Viewer left behind (caches,
  crash reports, the old 2.0.0 temporary folders, and, if you choose, your settings)
  and removes what you tick. Your macros, saved plots and builds are always kept.
  On Windows, uninstall from Settings > Apps; on a Mac, run **Uninstall AMPM
  Viewer** from the disk image.
- **Filter buttons** on the Data toolbar now sit right after the column buttons.

### First start on a Mac

The Mac app isn't signed by Apple yet, so macOS stops it the first time:

- **macOS 15 (Sequoia) and later:** open AMPM Viewer, close the warning, then go to
  System Settings > Privacy & Security and press **Open Anyway** beside AMPM Viewer.
- **macOS 14 and earlier:** Control-click AMPM Viewer in Applications, choose
  **Open**, then **Open** again.

After that it opens normally.

### Upgrading from 2.0.0

The 2.0.0 download was a single `.exe` with nothing installed. Run the new setup;
you can then delete the old `.exe`. Settings, macros and the plot library are kept
(they live in `%APPDATA%\AMPM`).

See `CHANGELOG.md` in the repository for the details.
