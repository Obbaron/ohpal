# AMPM Analyzer User Guide

The user guide now lives inside the app: press **Help** in the title bar (or
**F1**). It opens on the article for whatever you are doing, and every article
is searchable. The articles are plain Markdown files in
[`apps/ampm_analyzer/src/ampm_analyzer/shell/assets/help`](../apps/ampm_analyzer/src/ampm_analyzer/shell/assets/help),
so they can also be read here.

| Section | Articles |
| --- | --- |
| Getting started | Welcome to AMPM Analyzer; About the data; Opening a build; Setting up the DataStore; Create Excel from AMPM |
| Data | The Data tab; Calculated columns; Label columns; Adding a column from Excel; Renaming, removing and restoring columns; Parts; Filters; Exporting to Excel; Undo and redo; Macros |
| Plots | Creating a plot; Scatter plots; Layer plots; Bar charts and histograms; CoV summary; KDE and violin plots; Contour plots; K-distance curve; Viewing and styling a plot; Editing plot text; Plot windows |
| Reference | Settings, status bar and log; Keyboard and mouse; When something goes wrong |

This page previously described the 1.x interface (the Config and Analysis tabs
and drop-in plot views), which was replaced in 2.0.0; see the
[changelog](../CHANGELOG.md).
