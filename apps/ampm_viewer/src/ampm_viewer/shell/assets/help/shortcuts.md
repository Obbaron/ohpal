# Keyboard and mouse

On a Mac, use **Cmd** where this page says **Ctrl**. A toolbar button with a
shortcut shows it in its tooltip.

## Keyboard

| Keys | Does |
| --- | --- |
| **F1** | Opens help for what you are doing |
| **Ctrl+B** | Shows or hides the side panel |
| **Ctrl+Z** | [Undo](help:undo-redo) |
| **Ctrl+Shift+Z** or **Ctrl+Y** | Redo |
| **Ctrl+O** | Opens a build |
| **Ctrl+W** | Closes the build and every plot (**File ▸ Close**) |
| **Ctrl+,** | Settings |
| **Ctrl+Tab** or **Ctrl+PgDown** | Next tab |
| **Ctrl+Shift+Tab** or **Ctrl+PgUp** | Previous tab |
| **Enter** | Confirms a header rename or a dialog |
| **Esc** | Cancels a header rename or a dialog; in the grid, clears the selection |

## Data tab keys

| Keys | Does |
| --- | --- |
| **Alt+Down** / **Alt+Up** | Next / previous layer |
| **F2** | Renames the selected column |
| **Ctrl+F** | Adds a [filter](help:filters) |
| **Ctrl+N** | Opens the **New plot** menu |
| **Ctrl+E** | [Exports to Excel](help:export-excel) |

## Plot keys

These work in a [pop-out window](help:plot-windows) too.

| Keys | Does |
| --- | --- |
| **Ctrl+0** | Resets the view |
| **Ctrl+Shift+S** | Saves a screenshot |
| **Alt+Down** / **Alt+Up** | Next / previous layer (Layer Viewer) |

## Window

| Action | Does |
| --- | --- |
| Drag the empty part of the title bar | Moves the window |
| Double-click it | Maximises or restores the window |
| Drag an edge or corner | Resizes the window |

## Data tab

| Action | Does |
| --- | --- |
| Click a header | Selects the column (Ctrl or Shift for several) |
| Click empty grid or toolbar space | Clears the selection |
| Drag a header | Moves the column |
| Drag a header's edge | Resizes the column |
| Double-click a header | Renames the column |
| Double-click a cell | Opens the column's details in the side panel |
| Click a filter chip | Edits that filter |

## Plots

| Action | Does |
| --- | --- |
| Drag | Pans (2D) or rotates (3D) |
| Scroll | Zooms |
| Right-drag | Zooms (2D) or pans (3D) |
| Shift + drag | Pans a 3D plot |
| Hover a point or bar | Shows its values |
| Click a title, axis, label, colour bar, legend or the data | Selects it (an open side panel shows its [editor](help:plot-elements)) |
| Double-click it | Opens the side panel on its editor |
| Click empty space (plot or toolbar) | Deselects |
| Drag the slider (Layer Viewer) | Moves through the layers |

## File tab

| Action | Does |
| --- | --- |
| Double-click a recent build or plot | Opens it |
| Click a row's star | Adds it to or removes it from Favourites |
| Click a setup page group's title | Folds or unfolds it |
