# Layer plots

Both are top-down scatter plots of one layer, drawn to scale. They differ in
whether the layer can change.

## Layer Viewer

Shows one layer and has a **slider** under the plot. Drag it to move through
the build; the plot redraws for each layer you stop on. The view does not
reset as you move, so you can zoom into one part and watch it layer by layer.
The current layer is shown beside the slider.

## Single Layer

Shows the one layer you pick in the dialog, and stays on it. Use it when you
want a fixed picture of a particular layer, to compare with another plot or
to save as an image.

## Choosing what to show

Both ask for **X**, **Y** and **Colour by**, like a
[2D scatter](help:plot-scatter). Hovering a point shows its values.
