# Keyboard and mouse

## Keyboard

| Keys | Does |
| --- | --- |
| **F1** | Opens help for what you are doing |
| **Ctrl+Z** | [Undo](help:undo-redo) |
| **Ctrl+Shift+Z** or **Ctrl+Y** | Redo |
| **Enter** | Confirms a header rename or a dialog |
| **Esc** | Cancels a header rename or a dialog |

## Window

| Action | Does |
| --- | --- |
| Drag the empty part of the title bar | Moves the window |
| Double-click it | Maximises or restores the window |
| Drag an edge or corner | Resizes the window |

## Data tab

| Action | Does |
| --- | --- |
| Click a header | Selects the column (Ctrl or Shift for several) |
| Drag a header | Moves the column |
| Drag a header's edge | Resizes the column |
| Double-click a header | Renames the column |
| Double-click a cell | Opens the column's details in the side panel |
| Click a filter chip | Edits that filter |

## Plots

| Action | Does |
| --- | --- |
| Drag | Pans (2D) or rotates (3D) |
| Scroll or right-drag | Zooms |
| Shift + drag | Pans a 3D plot |
| Hover a point or bar | Shows its values |
| Click a title, axis, label or colour bar | Selects it |
| Double-click it | Opens its [editor](help:plot-elements) |
| Drag the slider (Layer Viewer) | Moves through the layers |

## Start page

| Action | Does |
| --- | --- |
| Double-click a recent build | Opens it |
| Click a build's star | Adds it to or removes it from Favourites |
